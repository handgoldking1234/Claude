접속 준비

아래 순서대로 한 번만 해두면 목록의 링크가 바로 열립니다.

  1. 개발 서버 실행

    npm run dev는 --mode development로 뜹니다. npm run local은 모드가 달라 3번 항목이 적용되지 않으니 쓰지 마세요.

    cd D:\depth\front
npm run dev

    서버 주소 — http://127.0.0.1:3100

  2. 로그인 후 액터 전환

    화면마다 필요한 액터가 다릅니다. 로그인한 뒤 헤더 우측 액터 선택기에서 해당 액터로 바꾸세요. 여러 액터를 가진 계정이면 재로그인 없이 전환됩니다.

    Master(ACT-00) 계정은 rightwrite를 포함한 모든 경로를 그대로 통과합니다.

  3. 메뉴 가드는 이미 꺼져 있습니다

    .env.development 42번 줄에 VITE_DISABLE_MENU_GUARD=true가 들어 있어, 계정에 메뉴가 매핑되지 않은 화면도 주소만 치면 열립니다. 퍼블리싱·반응형 확인용으로 열어둔 개발 전용 스위치이고 운영 빌드에서는 켜지지 않습니다.

    단, /rightwrite/**는 메뉴가 아니라 코드에 액터가 박혀 있어 이 스위치로 뚫리지 않습니다. 해당 액터로 전환해야 합니다.

  4. 좁은 폭으로 보기

    F12 → 디바이스 툴바(Ctrl+Shift+M) → 폭을 640px 이하로. 카드형 전환 기준점은 sm = 640px입니다. 이 목록의 표들은 이 폭에서 가로 스크롤로 남습니다.

  5. ID는 목록에서 받아오기

    아래 링크는 전부 목록 화면으로 연결됩니다. 아무 건이나 눌러 들어가면 주소창에 designId·assignmentId가 찍히고, 그 뒤 '도달 경로'대로 이동하면 해당 표가 나옵니다.
