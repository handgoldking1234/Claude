확인이 필요한 점 4

1. 빈 목록일 때 문구

rangeStart={0} 을 넘기면 현재 0–0건 / 총 0건 으로 나옵니다. 컴포넌트는 rangeStart != null 이면 구간을 그리므로 0 도 유효한 값으로 봅니다. 전체 0건 으로 보이게 하려면 빈 목록에서 rangeStart·rangeEnd 를 undefined 로 넘겨야 합니다. 어느 쪽으로 통일할지 정해 주세요.

2. 로딩·에러 중 건수

지금 화면마다 다릅니다. {'{loading || error ? 0 : rangeStart}'} 처럼 0 으로 눌러 두는 곳도 있고 그대로 두는 곳도 있습니다. 컴포넌트는 loading·error 분기를 갖지 않는 것이 설계 의도라(가이드 설명 명시), 호출하는 쪽에서 계산해 넘겨야 합니다. 이것도 규칙을 정하는 편이 좋겠습니다.

3. 단위 표기

건(기본) · 명 · 개 가 섞여 있습니다. 지금 값을 그대로 옮길지, 대상에 맞춰 다시 정할지 확인이 필요합니다.

4. 푸터에 버튼이 있는 경우

메시지코드 화면은 푸터에 취소·저장 버튼이 들어 있습니다. children 으로 넣을지, info 로 좌측을 통째로 대체할지, 아니면 푸터를 분리할지 판단이 필요합니다. 같은 형태가 더 있는지는 전환하면서 드러날 것으로 봅니다.
