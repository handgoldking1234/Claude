공통 컴포넌트 01

없어서 각자 만들던 것을 만들고, 있는데 안 쓰던 곳을 옮겼습니다.

이름구분내용
HelpTooltip신설 제목 옆 도움말. MainHeader 안에만 있어 다른 곳에서 쓸 수 없던 마크업을 분리했습니다. Panel 에도 tooltip prop 을 열어 패널 제목 옆에 붙습니다. 컨테이너는 div → span — h1·h2 안에 div 는 올 수 없습니다.

Modal보강 role="dialog" · aria-modal · ariaLabel 추가. 이를 쓰는 팝업 52곳이 한꺼번에 얻습니다. 문항 생성 모달을 공통으로 옮기다 그쪽이 갖고 있던 것을 잃게 돼 발견했습니다.
HelpBanner보강 role prop(note/status/alert). 없으면 평가설계 안내문 10곳을 옮길 때 오류(alert)와 안내(status) 구분이 사라집니다.
BoxTabs보강 래퍼에 box-tabs 클래스. 유틸 클래스뿐이라 바깥에서 가리킬 수 없었습니다. 통계 조회의 직접 만든 탭도 이 컴포넌트로 옮겼습니다.
Panel이관 답안 보기 팝업의 01 02 03 번호 카드를 공통 패널로. 전용 CSS 120줄 삭제.
한 번 더 정리가 필요한 곳

팝업 푸터 버튼은 아직 컴포넌트가 아닙니다. Modal 은 footer 를 ReactNode 로 받기만 하고 내용은 호출하는 쪽이 매번 씁니다. 그래서 이번에 그림자를 넣을 때 45개 파일 77개 버튼을 일일이 고쳐야 했습니다. ModalActions 로 묶으면 다음부터는 파일 한 개만 고치면 됩니다.

--metricbar-divider: rgba(255, 255, 255, .22);
--metricbar-label: rgba(255, 255, 255, .78);

--metricbar-divider-v: linear-gradient(180deg, transparent,

모바일 필터 03

라벨과 컨트롤이 형제로 나란히 놓여 있어, 줄이 바뀌면 라벨만 윗줄에 남고 컨트롤이 떨어졌습니다.

.ui-filters-field {
  --ui-filters-field-cols: 2;
  display: flex; flex-wrap: wrap; align-items: center;
}
.ui-filters-field--3col { --ui-filters-field-cols: 3; }
.ui-filters-field--4col { --ui-filters-field-cols: 4; }
.ui-filters-field--5col { --ui-filters-field-cols: 5; }

@include respond-to(sm) {
  .ui-filters-field {
    flex-direction: column; align-items: flex-start; width: 100%;
    > b, > span { width: 100%; }                    /* 라벨은 무조건 윗줄 */
    .box-tabs, > .ui-filters-group {
      display: grid;
      grid-template-columns: repeat(var(--ui-filters-field-cols), minmax(0, 1fr));
    }
  }
}
flex 가 아니라 grid

flex 로 두면 전체 (288) 와 응답 대기 (3) 의 글자 길이가 달라 칸 폭이 들쭉날쭉해지고 계단처럼 보입니다. grid 는 칸이 균등합니다.

열 수는 라벨 길이로 정합니다

변형쓰는 때
기본 2열라벨이 길거나 탭이 2개. 건수가 붙는 라벨(전체 (12))도 여기
--3col탭이 3개(딱 맞음) 또는 5~6개
--4col / --5col짧은 라벨. 글자를 한 단계 줄여 고정하고 좌우 여백 축소
--compact열 수와 무관하게 글자만 줄임. 3열인데 라벨이 긴 경우
말줄임이 높이를 바꿨다

칸을 넘칠 때 줄바꿈이 아니라 말줄임입니다 — 한 칸만 두 줄이 되면 그 줄 전체 높이가 어긋납니다. 그런데 text-overflow 는 flex 항목에 걸리지 않아 display: block 이 필요하고, 그러면 .btn 의 세로 가운데 정렬이 사라져 line-height 로 대신 맞춰야 합니다. 이때 위아래 padding 4px 을 함께 지우지 않아 이 탭만 44px 로 커져 있었습니다(다른 탭은 36px). padding: 0 var(--ui-space-1) 로 바로잡았습니다.

검색 버튼

검색창 뒤에 붙는 버튼을 훑어 11군데를 찾았고, type 으로 정확히 갈렸습니다 — 검색 실행은 submit, 새로고침은 button + .square 아이콘. 페이지를 하나씩 고치지 않고 CSS 하나로 구분됩니다. 

.ui-filters-slot:has(.btn[type="submit"]) {
  flex-wrap: wrap;
  > .search-input-wrap, > .form-input { flex: 1 1 100%; }
  > .btn[type="submit"] { width: 100%; }
}
width 로는 줄이 갈리지 않는다

flex-basis: 100% 가 실제로 줄을 가르는 부분입니다. flex 줄바꿈은 줄어들기 전 크기로 판단하는데, width: 100% 만으로는 그 기준이 여전히 flex-basis(0 또는 auto)라 버튼이 옆에 남습니다.

탭 생김새

.box-tabs .btn.btn-primary { background: var(--ui-primary); }  /* 그라데이션 제거 */
@include respond-to(sm) {
  .box-tabs .btn.btn-empty { border-color: var(--ui-border); }
}
두 번 다 명시도에 걸렸다

.box-tabs .btn-empty(0-2-0)는 같은 파일 뒤쪽의 .btn.btn-empty(0-2-0)에 졌습니다. 같은 값이면 뒤에 오는 쪽이 이깁니다. 미디어쿼리는 명시도를 올려 주지 않습니다. .btn 을 함께 걸어 0-3-0 으로 올렸고, 선택된 탭의 단색 처리도 같은 이유로 같은 형태입니다.

툴팁 04

잘린다는 지적이 네 번 있었고, 매번 원인이 달랐습니다.

증상원인과 처리
패널에서 윗부분 잘림 .ui-panel 이 둥근 모서리 때문에 overflow: hidden. 768 이상에서 툴팁은 버튼 오른쪽에 세로 가운데로 붙는데, 버튼보다 키가 크면 위쪽 절반이 패널 밖으로 나갑니다.
고쳤는데 그대로 SCSS 중첩에서 & 를 잘못 써서 호버 규칙이 존재하지 않는 구조로 컴파일됐습니다. 기본 규칙이 이겨 translate(0, -50%) 가 그대로 걸렸고, 넣어 둔 top: 0 이 무용지물이었습니다.
글이 길면 또 잘림 가운데 정렬은 길어질수록 위로 더 올라갑니다. 패널만이 아니라 전역 규칙 자체를 버튼 윗선 기준으로 바꿨습니다 — 이제 길어지는 만큼 아래로만 자랍니다.
목록에서 잘림 세로 스크롤 목록은 위·아래 어느 쪽도 안전하지 않습니다(첫 행·마지막 행). btn-icon--tip-left 로 옆에 둡니다 — 툴팁 높이가 행 높이를 넘지 않습니다.
화살표 위치

상자를 10px 올리면 ::before 도 따라 올라갑니다. 화살표는 툴팁 기준으로 위치를 잡기 때문에, 올린 만큼(5px → 15px) 되돌려 더해야 아이콘을 계속 가리킵니다. 기준값은 버튼 높이 19px(아이콘 17 + 테두리 2)의 절반에서 화살표 반높이(5px)를 뺀 값입니다.

남은 것 07

확인이 필요한 것

ModalActions — 팝업 푸터 버튼을 컴포넌트로 묶을지. 지금 btn-shadow 77곳이 여기로 흡수됩니다. 취소 버튼이 btn-outline 과 btn-white 로 섞여 있어 어느 쪽으로 통일할지도 함께 정해야 합니다.

직접 짠 팝업 16개 — .ui-modal__footer 마크업을 직접 쓰고 있습니다. 문항 생성(신규 UX)만 공통 Modal 로 옮겼습니다.

.eval-ai-card 40곳 — 공통 Panel 로 옮기면 AI 모달 전체의 생김새가 바뀝니다. 범위 확인이 필요합니다.

선택 카드 teal 계열 — 리포트 생성의 tpl-card, 연합 생성 다이얼로그 2종, 선임 지정 2종이 아직 자기 색을 씁니다. teal 을 유지한 채 옮길지, 파랑으로 통일할지.

남겨 둔 것

알파가 붙은 rgba(37, 99, 235, …) 47곳 — 소스에 #2563eb 문자열이 아니고, var() 는 rgba() 안에 넣을 수 없어 color-mix() 로 바꿔야 합니다.

#1d4ed8 6곳 — 전부 버튼 호버 색입니다. 이제 --blue-700 이 있으니 그 이름으로 모을 수 있습니다.

colgroup 없는 표 43개 — 열이 많을수록 증상이 심합니다. 내부표준화 상세(11열·9열) · 선임관리(8열) 순입니다.

격자로 세우지 않은 탭 2곳 — 외부 API 사용량은 라벨이 HyperCLOVA X STT 처럼 길어 격자에 넣으면 전부 말줄임됩니다.

컴포넌트 가이드 — /front-component-layout 의 조회 범위 예시가 옛 구조라 실제 화면과 어긋납니다. ui-filters-field · option-card · HelpTooltip 항목도 아직 없습니다.
