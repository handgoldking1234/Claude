전 화면 일괄 적용

개별 화면 표에는 다시 적지 않았습니다. 아래 네 가지는 해당하는 모든 화면에 반영돼 있습니다.

주 버튼 색 통일 59곳

  • btn-teal → btn-primary. 저장·등록·확정 등 주 액션 전부
  • 사용처 0. 배지의 badge-teal은 별개이므로 유지

페이지 헤더 버튼 규격 71개

  • btn-shadow 적용, btn-lg 제거 → 높이 36px 통일
  • 보조 버튼 btn-outline → btn-white (13곳)

모달 푸터 버튼 아이콘 25곳

  • 취소·닫기 IconClose / 저장 IconSave / 확인 IconCheck / 삭제 IconDelete
  • 저장 중에는 IconLoading으로 교체, 아이콘은 텍스트 앞 size={15}

전역 스타일 손질 공통

  • 셀렉트 화살표 복구 — .menu-form-field select의 background 단축 속성이 화살표 이미지를 지우던 버그
  • 셀렉트 우측 여백 — .form-select의 padding-right 24px → 30px. 화살표와 글자가 붙던 것을 띄움
  • 구분자 세로 정렬 — .box 안의 장식용 –·h-bar가 줄 위쪽에 붙던 것을 align-self: center로 정렬
  • 셀렉트 폭 변형 추가 — select-search--filter-auto(내용 폭·최소 130px). 기존 --filter는 180px 고정
  • 파비콘 — 신규 SVG 심볼로 교체. Illustrator가 만든 한글 그라디언트 id를 ASCII로 정리해 인코딩 의존 제거

적용한 규칙 요약

새 화면을 만들 때 이대로 맞춰 주세요. 전부 기존 클래스만 쓰며 신규 CSS는 셀렉트 폭 변형 하나뿐입니다.

목록 표 열 폭

<th style>에 흩지 말고 <colgroup>에 모읍니다. 표에 min-width를 걸면 %가 최소 폭이자 확대 비율로 동작합니다.

<table style={{ minWidth: '1000px' }}>
  <colgroup>
    <col style={{ width: '56px' }} />  No — px
    <col style={{ width: '26%' }} />   이름 — 넓게
    …
  </colgroup>

/* css — col width 를 쓰려면 필수 */
.표 { table-layout: fixed; }

표 정렬

  • <th>는 모두 가운데
  • <td>도 기본 가운데, 이름·경로처럼 긴 텍스트 열만 text-left
  • 아이콘 버튼이 들어가는 관리 열은 px 고정 + 가운데

필터바 구분선

  • 성격이 다른 필터 묶음 사이에만 <div className="h-bar" />
  • 오른쪽 검색창 앞에는 넣지 않습니다
  • 앞머리 라벨은 <span className="text-muted-light text-xs font-bold">

검색 가능 셀렉트

  • 옵션이 API로 채워지고 개수가 많으면 SelectSearch
  • 학교급·학년처럼 선택지가 몇 개뿐이면 <select> 유지
  • 폭 — 값이 길면 select-search--filter(180px), 짧으면 select-search--filter-auto(내용 폭·최소 130px) 신규

주의할 점

원인 찾는 데 시간이 걸렸던 것들입니다. 같은 증상을 만나면 여기부터 보세요.

증상원인과 대처
셀렉트 화살표가 안 보임
  • .form-select는 화살표를 background-image로 깝니다. 컨테이너 규칙이 background 단축 속성으로 배경색을 덮으면 이미지까지 지워집니다
  • background-color로 분리하고, padding도 덮였다면 padding-right를 다시 확보
<col>의 min-width가 안 먹음
  • <col>에 적용되는 건 width·background·border·visibility 정도입니다
  • 폭은 width를 %로, 최소 폭은 <table>의 min-width로
패널 안 툴팁이 잘림
  • .ui-panel이 overflow: hidden이라 오른쪽 끝 버튼의 툴팁이 잘립니다
  • header-tooltip-host--edge를 함께 주면 안쪽으로 펼쳐집니다. 툴팁을 달면 title은 제거
