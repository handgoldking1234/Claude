무엇을 왜 바꿨나

공통 Panel 컴포넌트는 제목과 설명을 아래 구조로 렌더합니다. 설명은 제목 아래 줄에 ui-panel__title-description으로 들어갑니다.

기준 구조

<h2 class="ui-panel__title flex flex-col gap-1">
  <div class="flex items-center gap-4">
    <span class="inline-block">배정 대상 목록</span>
  </div>
  <div class="ui-panel__title-description">
    비활성화는 해당 평가에만 적용되며…
  </div>
</h2>

어긋나 있던 두 가지

  • 설명이 제목 옆에 — subTitle은 제목과 같은 줄에 렌더됩니다. 설명문을 여기 넣은 곳이 70곳이었습니다
  • 헤더를 손으로 작성 — <section class="ui-panel">부터 직접 쓴 화면은 설명 슬롯이 아예 없어, 제목 옆 <span>이나 별도 <h3>으로 대신하고 있었습니다

전 화면 일괄 적용

개별 화면 표에는 다시 적지 않았습니다.

설명을 제목 아래로 70곳

- subTitle="현재 관리 범위에 적용되는 보존 기간"
+ description="현재 관리 범위에 적용되는 보존 기간"

문자열 59곳 + JSX 11곳. 배지·카운트처럼 제목 옆이 맞는 것은 subTitle로 그대로 뒀습니다.

군더더기 태그·클래스 제거

- subTitle={<span>복수 역할 보유 가능</span>}
+ description="복수 역할 보유 가능"

- subTitle={<span className="text-muted">신청번호: {…}</span>}
+ description={`신청번호: ${…}`}

<span>은 역할이 없었고 text-muted는 ui-panel__title-description이 이미 하는 일입니다.

전역 CSS 정리 4건

  • 패널 그림자 완화 — .ui-panel이 --ui-shadow-sm보다 옅게. 패널이 여러 개 쌓이는 화면에서 진해 보였음
  • 아이콘 버튼 정사각 — .btn-sm.square에 min-width: 30px. 아이콘 크기에 따라 폭이 달라지던 문제
  • 규칙 삭제 — .menu-admin-page .btn-primary가 공통 버튼색을 덮고 있어 제거
  • 전용 헤더 CSS 미사용화 — menu-tree-panel__header 계열이 공통 Panel 전환으로 사용처 0

정렬 교정

  • 안내 배너 — no-warp이 align-items: flex-start를 함께 걸어 한 줄 문구가 아이콘보다 위로 뜸. 해당 배너에서 클래스 제거
  • 패널 설명 — subTitle → description으로 줄바꿈 위치 교정

통계 카드 공통 규격 08-27

화면마다 카드를 따로 만들거나, 공통 GridStatus를 쓰면서도 아이콘·상태색을 빠뜨려 모양이 갈렸습니다. 알림센터 카드를 기준으로 맞췄습니다.

기준 — 알림센터 카드

<GridStatus items={[
  { state: "teal", label: "전체", value: …, unit: "건", icon: <IconBell size={18} /> },
  { state: "danger", label: "안읽음", value: …, unit: "건", icon: <IconFile size={20} /> },
]} />

GridStatus는 icon이 있을 때만 grid-stat__row 레이아웃(값·아이콘 좌우 배치)을 렌더합니다. 아이콘을 안 넘기면 같은 컴포넌트인데도 다른 모양이 나옵니다.

상태색 규칙은 ReportStatisticsPage 주석을 따릅니다 — primary 핵심 지표 / sys 부가 지표 / ok 상위 / warm 주의 / danger 경고.

패널 헤드 아이콘 08-27

같은 화면 안에서도 어떤 패널은 제목 앞에 아이콘 배지가 있고 어떤 패널은 없어 헤더 높이와 정렬이 갈렸습니다. 코드 전체의 <Panel> 여는 태그를 파싱해 icon이 빠진 곳을 전수조사했습니다.

전수조사 결과 — 42곳 / 22개 파일

  • 12곳 처리 — 아래 7화면
  • 24곳 보류 — 채점관리·평가시행. 개발 중이라 제외
  • 6곳 대상 아님 — title이 없어 헤더 자체가 렌더되지 않는 <Panel>. 아이콘이 들어갈 자리가 없습니다

적용 규격

<Panel icon={<IconList size={18} />}
       iconType="primary"
       title="리포트 목록"
       …>

모두 size={18} + iconType="primary". 코드베이스 전체에서 primary가 21곳으로 가장 많이 쓰여 이를 따랐습니다. iconType을 안 주면 기본값은 청록 배지입니다.

라디오 버튼 08-27

알약형 라디오(label-radio)의 항목 간격이 화면마다 gap-2·gap-3·gap-4로 갈려 있었습니다. gap-2로 통일하고, 단일 선택인데 체크박스로 그려지던 곳 하나를 라디오로 바꿨습니다.

간격 통일 6곳

- <div className="flex items-center gap-4">
+ <div className="flex items-center gap-2">

전수조사로 label-radio 그룹 래퍼 10곳을 찾아 6곳을 수정, 나머지 4곳은 이미 gap-2였습니다. gap- 토큰만 바뀌고 flex·flex-wrap·items-center와 JSX 구조는 그대로입니다.

형태 교정 1곳

- <LabelCheckbox IsCheck={category === item.value}
-                event={() => setCategory(item.value)} …>
+ <label className="form-label label-radio label-sm">
+   <input type="radio" name="community-category" …/>

하나만 고를 수 있는데 네모 체크박스로 보이던 곳입니다. name도 함께 붙였습니다 — 라디오는 name으로 묶여야 방향키 이동과 스크린리더 그룹 인식이 동작합니다.
