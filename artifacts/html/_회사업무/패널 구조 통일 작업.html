패널 장식이 이중으로 걸려 있었음

.aid-panel / .wd-panel이 자체 배경 · 테두리 · 패딩을 갖고 있어 ui-panel을 씌우자 패딩이 두 번 들어갔습니다. 장식은 공통 패널에 맡깁니다. 

.aid-panel {
  display: flex;
  flex-direction: column;
/* 배경·테두리·패딩·간격은 공통 ui-panel 이 담당 */
}

제목이 가운데로 밀리던 이유

헤더에 justify-content: space-between이 걸린 상태에서 자식이 셋(아이콘 · 제목 · 범례)이 되면 제목이 한가운데로 갑니다. 제목이 남은 폭을 차지하게 두면 됩니다. 

.aid-panel__head { gap: var(--space-3); }
.aid-panel__head .ui-panel__title {
  flex: 1 1 auto;
}

버튼의 자체 색 규칙을 지우고 공통 .btn에 넘길 때, 같은 블록에 있던 grid-column·width까지 함께 날아가 카드 격자가 무너졌습니다. 생김새는 공통 클래스에, 배치는 화면 CSS에 — 둘을 나눠 남깁니다. 

/* 생김새는 공통 .btn 이 담당하고 배치만 잡는다 */
.union-seed-step > .btn {
  grid-column: 1 / -1;
  align-self: end;
  width: 100%;
}

+ color: var(--ui-primary);
- background: linear-gradient(145deg, #176b75, #3551a3);
