Open items

4 outstanding
  • Drift

    The sign-in screen predates the tokens.

    It was drawn first and the variables were derived from it afterwards, so its fills are still hardcoded and four of them land a shade off the token they should bind to: labels #262933 vs gray/900, body #171721 vs gray/900, placeholders #9499A5 vs gray/400, and secondary text #595E6B vs gray/700. Binding the screen to variables closes all four.

  • Next

    The Components page is still empty.

    Six patterns above are ready to be built as real components with variant sets — Button (primary / secondary × default / hover / disabled), Input (default / focus / error / filled), Checkbox (checked / unchecked), Card, Text link.

  • Gap

    Only one color mode exists.

    The Color collection has a single Light mode. A Dark mode is one column away — every semantic token already aliases a primitive, so dark is a matter of re-pointing seven aliases, not redefining values.

  • Blocked

    The plan caps the file at three pages.

    Figma's Starter plan allows three pages per file, which is why Cover and per-component pages were folded into Examples · Foundations · Components. A component-per-page structure needs a Professional Full seat.
