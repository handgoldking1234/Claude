게임패드

버튼X① Y② A③ B④ · RB 분노 · START 일시정지
패드 1 → 1P, 패드 2 → 2P
  • 가드: 가만히 있거나 뒤로 → 상단·중단 가드. 앉아 있으면 하단 가드. 중단은 서서만 막힌다.
  • 상단은 앉아서 피한다. 피한 뒤 일어서며 ②로 띄워서 콤보.
  • 띄우기 → 콤보: ↘+②로 띄우고 ①, ② → ←+④처럼 공중에서 이어 때린다.
  • 사이드스텝으로 직선 공격을 피한다. 돌려차기(←+④)는 옆으로 도는 상대를 잡는다.
  • 특수기 3종: ↓↘→① 장풍(연장·물건을 던지는 飛 도구), →↓↘② 승룡(발동 순간 무적 + 띄우기), ↓↙←③ 선풍(회전 돌진). 쓸 때마다 직업별 멘트.
  • 상황 멘트: 등장, 띄우기, 벽꽝, 카운터, 다운, 잡기 풀기, 라운드 승리 때마다 직업별 대사가 말풍선과 음성으로 나온다.
  • 필살기: 때리거나 맞으면 필살 게이지가 찬다. MAX일 때 ↓↘→↓↘→② (필살기 1, 중단) 또는 ↓↘→↓↘→③ (필살기 2, 하단 돌진) → 컷신 + 멘트. 둘 중 하나를 쓰면 게이지가 비워진다.
  • 장풍 상쇄: 서로의 장풍이 부딪히면 둘 다 사라진다. 상단 장풍은 앉아서 피할 수 있다.
  • 잡기: ①+③ / ②+④ (가드 불가). 잡혔을 때 ① 또는 ②를 빠르게 누르면 풀린다.
  • 벽꽝: 강한 기술로 울타리에 밀어붙이면 벽에 붙어 추가타 찬스.
