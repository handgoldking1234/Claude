- 초5 자녀가 '딱풀리는 수학' 공부방 스타일 학원에 다님, 주 3회 회당 1시간 40분
- 한 학기 선행 — 5-2 진도, 학원 보고서 기준 75~80점
- 집에서는 별도 숙제·공부 안 함
- 수업: 영상 개념 5분 → 문제 풀이 → 오답 정리 후 선생님 설명
- 수준별 방식은 대형 학원보다 낫다고 보지만, 아이가 뭘 어느 수준으로 하는지 파악이 안 되는 게 고민
