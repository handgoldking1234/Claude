- 수학연산 앱(2026-10), 초등부터 고등까지 확장, 조안호의 국민연산 참고
- 학습: 기초부터, 틀리면 반복, 계속 맞으면 진도, 3~5일 단위 반복 — 오답 반영 반복이 핵심
- 처음 단계는 개념설명을 읽어야 문제를 풂, 개념은 언제든 볼 수 있게 연동
- UI: 흰 바탕, 주색 당근색 + 블랙(노란색에서 변경), 조안호 연산 앱 화면 구조 참고, 아이콘 Lucide
- 한자(한국어문회 8급~1급): 부수부터, 틀리면 반복·맞으면 급수 진급, 3~5단계 간격 반복 — 연산과 한 앱으로 통합
- 과목 추가: 영단어(초→중→고), 역사(국사·세계사, 고등까지 튼튼하게), 국어(자주 틀리는 맞춤법부터, 빈도 분석; 어휘력은 김주혜 『시험 문해력 잡는 어휘 사전』 참고), 한글·영문 타자 게임, 과학(초·중·고 문제은행 + 개념·원리) — 과목마다 특징에 맞는 주색
- 한자·영단어는 초·중·고 필수 단어 중심
- 수학은 연산 위주, 세 자리 수 연산은 불필요, 기초 반복
- 아이패드·모바일 반응형
- 동기부여: 캐릭터, 정답마다 캐시 → 아바타 꾸미기; 대결방(방장 개설·초대·간단 채팅, 하루 횟수 제한)·스피드게임; 순위·등급
- 대시보드에서 오늘 할 일 지정 — 다 끝내야 아바타 꾸미기·대결 가능
- 점수·캐시 = 맞힌 문제 − 틀린 문제; 밀린 공부 체크, 설정 시간 알림
- 요금 검토: 가입자 코드 3개 발급 → 코드 수에 따라 과목 무료 개방 vs 한 과목 월 2만원·묶음 월 3만원
- 규칙 정의서를 개발 단계에서 사용
- 「하루」 접두어는 흔해서 고민
- 2026-10 말 HTML 프로토타입 완료 → Claude Code로 본개발, 무료 플랜·무료 서브도메인으로 시작
