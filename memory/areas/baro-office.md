- GitHub 저장소 handgoldking1234/office
- 디자인: 화이트 배경에 블루, 주색은 검정 (처음 스포티파이풍에서 변경), 아이콘 루시드, 마이크로소프트 모바일 앱 UI 참고

- 모바일에서는 툴바·버튼 아이콘만, 툴바는 피그마처럼 다양한 도구(사이드바·툴바 참고해 세부 설정)
