- 콜 오브 듀티 같은 1인칭 — 그래픽은 돈 안 드는 선에서 진짜같이, 야간투시경, 배경·플레이어·적·아이템 모두 무료
- 북한 침투편(더 사실적으로) → 무기·캐릭터·적 디테일, 공간이 연결된 맵 → 난이도 낮춤
- 이후 아군과 함께하는 대난투(팀전)로 변경 — 시작 시 야간투시경/열상 탐지기 선택, 근접·유틸리티, 무기 추가
- 그래픽 불만 → 무료 공개 에셋을 직접 받아 첨부하는 방식으로
- 군인 모델이 가장 중요 — 너무 비현실적이라고 봄
