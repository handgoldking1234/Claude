- 웹디자이너 대상으로 AI 활용(이미지 생성, 피그마 활용, HTML 변환·개발 적용, 바이브 디자인·바이브 코딩, 사이트 제작·운영 AI 활용) 강의 커리큘럼을 준비 중
- 초점은 AI 활용이며 피그마 교육이 아님; 실습 없이 시연과 설명을 섞어 진행
- 강의 분량을 2시간 단일 과정으로 한정하기로 변경 (이전 구상: 하루 4시간 × 7회)
- 커리큘럼에 수정사항 리포트(클로드 코드 작업 기록), 회의자료 기반 간단 이벤트 작업, 부분 퍼블 적용과 전체 개발소스 활용 퍼블 내용 포함
- 강의 주제를 "프로모션 페이지 제작"으로 좁힘 — 대상은 AI에 부정적인 기존 웹디자이너 실무자(피그마 이제 숙지, 회사는 아웃풋 속도를 요구)
- 사용 도구를 제미나이·클로드 2개로 한정, 미드저니는 제외
- 2시간 과정의 초점을 "디자인 + 퍼블리싱"으로 확정, 중복은 최대한 제거하고 실무 위주로 재구성
- Figma MCP·Code Connect는 짧은 시연만 하고 설치·연동 절차는 배포 자료로 대체하기로 함
- 강의 전체를 관통하는 결과물은 프로모션 페이지 1식 (기획 → 이미지 → 디자인 → 마크업 → 반응형 → 수정)
- 관련: [[claude-design-course]] (같은 소재의 장편 온라인 코스 버전)
- 배움사이버평생교육원 특강으로 확정 — 총 120분 · 5개 파트(오리엔테이션 10 / 제미나이 25 / 피그마×클로드 30 / 클로드 퍼블 40 / 실무 적용 15), 도구는 제미나이·피그마(AI/MCP)·클로드(클로드 디자인 포함)·디자인 MD·VS Code
- 강의 PPT는 기존 "AI_프로모션페이지_워크숍" 덱 디자인(보라 #6C5CE7 계열)을 따르고 프리텐다드 폰트 사용, 내용은 팩트 근거 필수 — 28장 초안 완료, 클로드 디자인에서 편집하기 위해 MD 원고(v2 전문성 강화판)로도 보관
- 배움 측 피드백(2026-09): STEP 2를 제미나이→ChatGPT로 변경 요청, 기존 ASP 시스템(전역 CSS 충돌 → CSS 지역화, 상·하단 EUC-KR과 UTF-8 신규 소스 인코딩 문제)과 월 1회 이벤트·랜딩·배너 교체 작업을 빠르게 적용하는 방법을 커리큘럼에 포함 요청 — 대표 보고 완료 상태, 최종 커리큘럼·교육비 정리 후 재보고하면 진행
- 피드백 반영 후 120분 6파트로 재구성(오리엔테이션 10 / ChatGPT 20 / 피그마×클로드 25 / 클로드 퍼블 25 / 기존 ASP 적용 25 / 이벤트 운영 15) — STEP 1에 "클로드 vs 챗GPT 양자택일 아닌 역할 분담(알려주는 일 vs 직접 해주는 일)" 추가, 청취자 이해용 상세 강의 문서(md)로 작성
- STEP 7 "실무 프로젝트 시연" 추가 — 별도 세션(약 100분): ① 프로모션 사이트·배너·반응형 ② 학점은행제 랜딩 시즌 교체(임시) ③ 쇼핑몰 제작·페이지 추가·수정·반응형 ④ KR플랫폼 어드민 — RFP·회의록을 통한 디자인 ⑤ 대구형 평가플랫폼 — 리액트 개발소스 작업 + 공유파일 소통 (어플 제작 노하우 제외)
- 최종 강의 페이지 확정(2026-09): 총 240분(4시간) 6파트 + Q&A — 워크플로우 이해 25 / ChatGPT 기획·카피·이미지 40 / 피그마×AI 시안 45 / 클로드 HTML/CSS 퍼블 50 / 기존 ASP 적용 45 / 이벤트 운영 20 / Q&A 15, 케이스 스터디 5건 별도 소개, 프롬프트·체크리스트·DESIGN.md·CHANGELOG.md·이벤트 템플릿은 교육 후 배포 자료
- 강의 상세페이지(v5, 1920 데스크톱 1개)를 Figma 파일 XwN1fb9FFD0AS8zRwHSHZ2 "Page 2"에 html.to.design으로 임포트, Figma MCP로 작업 중 — 히어로 목업(1:2601)을 새 3D 캐릭터 이미지(남녀 + 클로드·피그마 아이콘)로 교체 예정, 구조 분석 완료(figma-page-analysis.md 기준, 재분석 불필요)
