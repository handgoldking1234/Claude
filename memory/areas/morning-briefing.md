- 매일 아침 자동 브리핑 — 대시보드(웹앱)에서 항목 추가·삭제
- 항목: 날씨, 주식 현황(유가·금 등 필수 지표), 관심 종목 최신 뉴스, 쿠팡·코스트코·이마트 전단 할인; 메일·문자 기반 일정 정리(연결 전)
- 관심 종목: 삼성전자, 하이닉스, 현대자동차, 현대모비스, 삼성전기, LG전자, 네이버
- 브리핑 항목을 추가·적용하면 반드시 테스트 실행 후 알림으로 확인
- ChatGPT·Gemini에서도 쓸 수 있는 프롬프트 버전 요청
- 퀀트 정보(계절성·변수·보유 종목)를 매일 아침 7시에 정리해 받기 — [[investing]]
- ※ 예약 작업(scheduled task)은 계정 귀속이라 새 계정에서 다시 만들어야 함
