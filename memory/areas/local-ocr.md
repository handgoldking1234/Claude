- 스캔 문서·공문서 → 텍스트 추출·변환·재가공, AI 또는 일반 PC에서 로컬로 — 경쟁사 분석·기획부터
- 본문과 직접 정한 항목을 추출해 항목별로 채움, 항목별 확인·개별/전체 복사로 업무 시스템에 옮기기 — 시스템 직접 입력까지 원함
- GitHub handgoldking1234/iux-ocr, 웹버전 자동 생성·업로드, 설치형은 exe
- 웹버전 주소 ocr.iux.kr
- PC 설치형은 인터넷 안 되는 환경 — 클라우드 OCR 엔진은 설치형 불가(웹버전에서만 검토)
- 최대 불만: 한글 손글씨·사인 인식 — 이미 손글씨 학습된 엔진을 가져와 커스텀하는 방식(로컬 적용)
