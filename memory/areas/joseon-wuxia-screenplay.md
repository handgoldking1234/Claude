- 중국 무협영화 '취도객'(醉刀客, 2025) 같은 시나리오, 조선 후기
- "우리나라는 활의 민족" — 검과 활이 주인공 무기, 총은 적 대장
- 3총사: 총·검·활을 잘 쓰는 세 사람 — 점진 합류(1편 활 한 명 → 끝에 한 명 합류 → 2편 셋째, 완전체)
- 악당: 왜·청과 결탁한 상인 또는 양반 / 시리즈마다 상인 → 세도가 → 청 → 왕급 권력자 → 일본 자객 → 영국 귀족으로 상승, 각국 무기·권법 업그레이드
- 궁수 배경: 호랑이가 부모를 잡아감 → 좌천한 장수에게 활을 배움 → 장수는 어명으로 처형, 그 뒤 상인과의 인연
- 서술: 박경리 『토지』처럼 장황·담대하게, 땅 기반
- 배경 지역: 함평 '호정' (호정골 아님)
