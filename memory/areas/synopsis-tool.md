- 작업 과정을 보고 시놉시스를 쉽게 만드는 툴 — 경쟁사 분석 후 진행, 이름 「시놉」, 단일 HTML
- 유형: 영화·드라마·숏컷 드라마·웹툰·웹소설·스토리텔
- 양식: 로그라인·기획의도·세계관·등장인물·줄거리(3막/기승전결)·셀링포인트 + 마크다운/AI 프롬프트 내보내기
- 인물 관계도: 얼굴 사진 업로드, 드래그 배치·연결, 클릭 시 관련 인물만 부각
- 디자인 스포티파이(다크 + 그린)
- AI 전체/항목별 생성, '캐릭터 시트' 모드 — 레퍼런스 사진 분석 → 생성 프롬프트, 그림은 외부(미드저니·Nano Banana)
- 웹툰보드 기획 부분에 통합 — 기획은 클릭 시 팝업, 콘티·AI 탭과 겹치는 부분 정리
