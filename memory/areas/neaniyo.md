- https://neaniyo.iux.kr, 저장소 handgoldking1234/neaniyo (main = Vercel 배포, feed 브랜치 = 자동 수집 투표)
- 연예·이슈 투표 공유 서비스, iframe 임베드, 매일 뉴스·SNS·유튜브 이슈 수집해 투표 생성 (이전 이름 판가름)
- 모바일은 앱처럼: 우상단 검색·계정·햄버거, 하단 탭바, 플로팅 버튼
- 사업자 등록·통신판매업 신고 있음, 결제(프리미엄)는 나중에
- 사이트 변경은 매번 묻지 말고 main에 머지해 자동 배포
- 관심사 기반 피드 — 팝업 대신 피드 안에서 묻고, 가입 시 건너뛸 수 있게
- Supabase(실제 투표 수, 로그인, 댓글, 사용자 생성 투표), 이메일(로그인 링크, 결과 알림, 관리자 알림), 백엔드 API 연결 희망
- 이메일 서비스는 아이유엑스 아트(iux)로 등록한 적 있음
- 백엔드는 공유 iux-cloud Supabase(IUX Cloud, [[iux-studio]]와 동일) 사용
- 출시 시 사용자 공개 투표는 사전 승인 없이 바로 메인 피드에
- "AI 예측 패널"은 폐기; 정식 출시 전까지 새 투표에 AI 시뮬레이션 참여, 실사용자 100명쯤 되면 제거
- 2026-11-18 계정 이전 시 네아니요 작업은 모두 GitHub에 올려 두길 원함
